# MEEDX design system
Palette: canvas #0B0B0D; surface #121215; raised #18181C; border #242429; action #E5B84B; available #22C55E; text #F4F2EB; secondary #B8B8BC.
Fonts: self-hosted IBM Plex Sans Arabic 400/500/600/700 for text; JetBrains Mono 400/500 for versions, sizes, hashes. Data uses LTR isolation and tabular numerals.
Composition: asymmetric device-led opening, TV wide frame with a separate phone frame. Shared 1280px content width, 24px mobile gutters. Quiet surfaces and real product screens. No invented metrics, neon gradients, identical SaaS grid, emoji, or automatic carousel rotation.
Spacing: 4/8/12/16/24/32/48/64/96. Controls >=44px, visible focus. Mobile drawers and scrollable bottom sheets. Desktop support uses a two-column dialog. Motion responds to interaction, reduced motion supported.
Explicit brief overrides skill defaults prohibiting carousels, mono data labels and requested carbon/gold palette. No random design dealing: composition, devices and palette are pinned by the user's detailed brief.
